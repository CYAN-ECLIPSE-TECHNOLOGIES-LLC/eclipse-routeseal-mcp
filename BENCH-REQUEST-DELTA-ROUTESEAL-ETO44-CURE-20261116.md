## What changed

- F-ETO44-1 (HIGH) — metering re-baseline cured in routeseal.py. The state file now persists the metering chain head + record count at every save (metering_head / metering_records, refreshed in memory after each save). At load, once a head/count has been recorded, ANY mismatch fails closed: journal truncated, journal file deleted, or state-file metering count inflated/deflated against journal + baseline all raise at load. metering_reconcile() reports recorded_head / recorded_records and counts a recorded mismatch as not reconciled.
- Migration honesty, stated plainly: baseline adoption survives ONLY for a state carrying no recorded head AND no journal records — the genuine pre-ETO-44 legacy case (probe M5c class), which still reconciles via the persisted baseline. A pre-cure state WITH journal records migrates only if journal + persisted baseline already reconcile EXACTLY with store counts; its head/count are adopted at the next save (migration happens once — after it, deletion/truncation fail closed). A pre-cure journal truncated before migration therefore fails closed; no baseline is ever invented for journal-era ops. Named boundary: a pre-cure journal deleted in full before any cured load is indistinguishable from the genuine legacy case and baselines once; every state the cured code has ever saved is protected thereafter.
- The ETO-44-era test that expected a deleted post-ETO-44 journal to baseline (the expectation the verdict ruled incompatible with M5) is reversed: test_licence_metering now pins deletion-fails-closed, plus a genuine-legacy baseline test that strips the recorded head/baseline keys and the journal to construct the true pre-ETO-44 shape.
- F-ETO44-2 (MED) — server.py wires LicenceGate UNCONDITIONALLY at the server face (ACT posture): with no licence state configured the gate is present in absent mode and a priced op is refused LICENSE_NOT_CONFIGURED, unmetered, exactly as M1 requires at the shipped face. Gate-absent is reachable only via the explicit, non-default opt-in ROUTESEAL_LICENCE_FIXTURE_BYPASS=1, announced on stderr. Store-level gate=None remains for tests only and is no longer reachable from the shipped wiring by default. smoke.py and the MCP-surface test opt into the bypass explicitly, by name.
- Ordering statement (per the verdict's M4 observation): in seal_dispatch the licence check precedes the idempotent-replay short-circuit, unchanged by this delta — a replay of an already-sealed capture after revocation is refused at the gate, and meters nothing. Filed as behaviour, not left emergent.
